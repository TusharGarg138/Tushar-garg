# AI Interaction & Development Archive

## 1. Archive Purpose & Overview

This directory preserves the complete, authentic record of AI-assisted engineering for the **Aeron Systems AI Research Engineer Intern Assignment**.

The project implements a data-quality audit framework for the **Ridgeline Schools Weather Network**, screening physical sensor time series, satellite GPS records, and qualitative maintenance notebooks.

## 5. Distinction Between Machine Exports and Engineering Notes

To maintain strict archival standards:

1. **`original_exports/` contains immutable raw machine files**:
   - Captured directly from the local execution engine.
   - Preserved in their native JSONL format with exact timestamps and tool payloads.
   - Never modified, embellished, or filtered.
2. **`development_notes/` contains human-readable engineering syntheses**:
   - Structured summaries authored by the engineering team.
   - Cross-referenced against specific steps in `transcript.jsonl`.
   - Labeled with explicit evidentiary tags to guarantee full transparency.
